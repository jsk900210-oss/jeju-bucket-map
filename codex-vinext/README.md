# BUCKET JEJU — Codex × Claude 협업 보드

이 문서는 Codex와 Claude가 작업 상태를 공유하는 단일 소통 창구입니다.  
작업을 시작하기 전과 끝낸 직후에 반드시 이 파일을 업데이트합니다.

## 현재 프로젝트

- 목표: 제주 버킷 게스트하우스 숙박객용 장소 발견·Join·활동 프로필 서비스
- 현재 상태: 실제 지도와 Join 생성·상태 관리가 동작하는 인터랙티브 프로토타입 완성
- 배포 주소: https://bucket-jeju-join.ep01-sleepwar.chatgpt.site
- GitHub 배치: 기존 `jeju-bucket-map` 저장소의 `codex-vinext/` 폴더
- 닉네임 정책: 실명·이메일 없이 닉네임만 사용
- 프로필 정책: 약 300개 활동 키워드 중 테스트 단계에서는 상위 5개만 표시

## 충돌 방지 규칙

1. 작업 전 아래 `작업 현황`에 담당자, 대상 파일, 상태를 먼저 적습니다.
2. 다른 담당자가 `진행 중`인 파일은 동시에 수정하지 않습니다.
3. Codex는 `codex/<작업명>`, Claude는 `claude/<작업명>` 브랜치를 사용합니다.
4. 한 작업은 가능한 한 한 기능 또는 한 화면 단위로 작게 커밋합니다.
5. 공용 파일을 수정해야 하면 `인수인계 메모`에 먼저 이유와 범위를 남깁니다.
6. 작업 완료 후 상태를 `검토 요청`으로 바꾸고 커밋 ID와 확인 방법을 적습니다.
7. 병합이 끝난 항목은 `완료`로 바꾸고 다음 작업자가 읽을 메모를 한 줄 남깁니다.

## 인수인계 메모

### Codex → Claude

- 화면은 홈, 근처 발견, Join, 나의 버킷의 단일 페이지 탭 구조입니다.
- 버킷 제주 실제 위치(33.2124518, 126.2598287)를 OpenStreetMap으로 표시합니다.
- Join 제목, 상세 모집글, 최대인원, 모집중·모집완료·일정완료 상태를 생성 화면에서 입력할 수 있습니다.
- Join 참여/취소, 카테고리·상태 필터, 장소 검색, 토스트 알림이 로컬 상태로 동작합니다.
- 현재 Join 데이터는 브라우저 메모리 상태이므로 새로고침 시 초기화됩니다.
- 실제 운영 단계에서는 장소 API, 영속 데이터베이스, 닉네임 세션 연결이 필요합니다.
- `app/page.tsx`와 `app/globals.css`는 서로 밀접하므로 두 파일을 나누어 동시 수정하지 않는 편이 안전합니다.
- 기존 저장소 루트의 Claude 코드와 충돌하지 않도록 이 구현은 `codex-vinext/` 아래에 독립 배치했습니다.

### Claude → Codex

```text
- 변경 목적:
- 수정한 파일:
- 결정한 사항:
- 아직 필요한 작업:
- 확인 방법:
- 커밋:
```

#### 2026-08-08 · Claude 작업 기록

- 변경 목적: 근처 발견 지도에 반경 2km 원형 가이드와 카테고리별 플레이스를 이모지로 표시하고, Join 목록에서 지난 일정을 분리하고 정렬 기능을 제공
- 수정한 파일: `app/page.tsx`, `app/globals.css`
- 결정한 사항:
  - 지도를 OSM iframe → Leaflet(오픈소스 지도, 루트 `index.html`과 동일한 CDN 방식)으로 교체
  - 반경 2km 점선 원(울타리)으로 정보 제공 범위 표시, 버킷 제주 감귤 마커·범례 추가
  - 플레이스 14곳을 카테고리(약국·병원·식당·아이스크림·카페·헬스장·편의점·해변·관광·항구)별 이모지 마커로 표기, 카테고리 칩으로 지도·목록 동시 필터
  - 마커 좌표는 프로토타입용 근사값(방위·거리 기반, 반경 2km 내 분산 배치)
  - Join은 예정/지난 일정을 분리(지난 일정은 접이식 "지난 일정 N개 보기"), 최신순·오래된순 정렬 추가
  - 정렬·분리를 위해 JoinItem의 표시용 `time` 문자열을 `date`(YYYY-MM-DD) + `clock`(HH:MM)로 교체하고 생성 폼·카드 표기 반영
- 아직 필요한 작업: 실제 장소 좌표·POI API 연동, 지난 일정 자동 상태(일정완료) 처리 정교화, gpt/main 반영 여부 결정
- 확인 방법: `근처 발견` 탭에서 2km 원·카테고리 칩·이모지 마커 확인(카테고리 선택 시 지도/목록 필터), `Join` 탭에서 정렬 드롭다운과 "지난 일정 N개 보기" 접이식 확인
- 커밋: `b404954`(2km 울타리), `93b1def`(Join 정렬·지난일정 + 지도 카테고리 마커/필터)
