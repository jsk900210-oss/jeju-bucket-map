# 프론트엔드 작업 정리

## 완료된 작업

- 제주 Join 30개 화면 구성
- `30개의 제주 Join` 문구 표시
- `v4 · Seed 20260731` 버전 표시
- 모바일 날짜 목록 가독성 개선
- Join 제목에서 `1일차`, `2일차` 등의 표현 삭제
- 합성 시드 데이터 안내 문구 삭제
- 모집 중·모집 완료 상태와 버튼 화면 구성
- 장소, Join, 프로필 기본 화면 구성
- 기존 Sites 프로젝트로 재배포
- 배포 파일과 URL의 API 키 노출 여부 확인
- 수정 내용을 GitHub `gpt` 브랜치에 1차 반영

## 앞으로 진행할 작업

- Google 로그인 버튼과 로그인 화면 연결
- 로그인 전·후 화면 상태 구분
- 사용자 프로필 화면 구성
- 내가 만든 Join 목록 구성
- 내가 신청하거나 취소한 Join 목록 구성
- 참여 기록 확인 화면 구성
- 백엔드 API와 실제 데이터 연결
- 로딩·빈 화면·오류 상태 추가
- 모바일 및 PC 화면 최종 점검

## Google 로그인 화면 연동 원칙

- 사용자 인증에는 Google OAuth를 사용합니다.
- 서비스에서 Google 비밀번호를 직접 수집하거나 저장하지 않습니다.
- 로그인 성공 후 백엔드에서 받은 내부 사용자 정보를 화면에 표시합니다.
- 로그인 여부에 따라 프로필, Join 생성·신청·취소 화면을 구분합니다.
